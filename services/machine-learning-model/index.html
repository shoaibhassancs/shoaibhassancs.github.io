Service

I will build and test a machine learning model from your raw data

Have data and want to predict something from it, like which customers will leave, which orders will be late, or which cases are most serious? I build and test machine learning models from your raw data, and explain the results in plain language.

How it works

  1. You send your data and tell me what you want to predict.
  2. I clean and prepare the data.
  3. I build a simple baseline, then an improved model, and test them honestly on data the model hasn't seen.
  4. You get the model, the code, and a clear report on how well it works and where it falls short.

Examples from the crime analysis project

Sample project, synthetic data. It shows my method, not real crime levels.

Basic example: model-ready data and a baseline model

The sample task: predict whether a crime incident is Low, Medium or High severity from crime type, location and date.

  • model_ready.csv Model-ready data ↓
  • 05_baseline_model.py Baseline model code ↓

Always guessing the most common answer (High) scores 55.1% accuracy (macro F1 0.237). The baseline model scores 89.6% (macro F1 0.876).

Standard example: tuned model and honest testing

Tuned with cross-validation on training data only, then scored once on 20,000 unseen incidents: 89.4% accuracy, macro F1 0.876. Mistakes happen only between neighbouring levels (Medium vs High, Low vs Medium). Low is never confused with High.

Tuning did not beat the simple model, and the report says so.
